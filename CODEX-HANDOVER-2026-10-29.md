## What changed (newest first)
- **Hero notepad** (`src/components/StickyNote.tsx`, CSS `.notepad*` in `globals.css`): a ruled notepad on the homepage. First page is the "Dear sea" note, then the most-felt public letters (`order felt_count desc`, skips letters with a content warning or crisis wording via `looksLikeCrisis`). Swipe/drag a page away to tear it (or the "Next page" button). Details that matter:
  - Each `Page` is a `forwardRef` component because `AnimatePresence mode="popLayout"` needs a ref to pop the exiting page out of the layout. Without it the pad grows while a page is leaving.
  - Pages have a **fixed height** (`h-[21.5rem]`); sign-off and button are pinned to the foot with `mt-auto`. Don't make the height content-based or the hero jumps.
  - `exit` uses `zIndex: 20` so the torn page flies in front of the fixed binding strip.
  - The side-by-side hero layout starts at `lg` (1024px). Below that the note sits under the headline. `.shore-hero { overflow-x: clip }` stops the orbit rings and bottle from causing sideways scroll.
- **Menu** (`Nav.tsx`): the "i" icon is now a three-line "Menu" button (desktop pill + phone). Panel rows: Contact us, Need help right now?, Surprise me, plus folds for "How it works" and "Our promise", and the Install row. **Mobile bottom nav is a full-width bar attached to the screen edge** (like Fodibey), not a floating pill. Things that sit above it (PWA install card, toast, main bottom padding, menu panel) were re-offset.

## Historical iPhone report — resolved 2026-10-30
Symptoms on the owner's iPhone (iOS 26/27): (1) Add to Home Screen shows a **generic black tile with an "I"** instead of the logo; (2) earlier, the installed/Safari page showed a **blank screen**. The Share preview was correct; this did not prove the installer could use the touch icon.
What was tried (all deployed):
1. Icons made opaque RGB squares (iOS paints transparency black). Files: `public/apple-touch-icon*.png`, `public/brand/png/icon-opaque-*.png`.
2. Manifest moved from `app/manifest.ts` to a **static `public/manifest.webmanifest`**, linked by hand in `layout.tsx` `<head>` **without** `crossorigin="use-credentials"` (Next adds that attribute to its own manifest link; suspected to make iOS drop the manifest icons).
3. Copied the owner's Fodibey/Badhige recipe (`~/Desktop/fodibey-copy/index.html` lines ~44-76): full `apple-touch-icon` set (plain, 152, 167, 180), `apple-touch-icon-precomposed`, and **`?v=N` on every icon URL**. iOS caches a home-screen tile per icon URL, even a failed generic one, and clearing Safari data does not clear it; only a new URL does. Current value: **`?v=6`** (in `layout.tsx` and `public/manifest.webmanifest`). **Bump it whenever the artwork changes or if the tile is still generic.**
4. Service worker `public/sw.js` is **v7** and returns early (no `respondWith`) for `/apple-touch-icon*`, `/manifest.webmanifest`, `/favicon*`, and hands Safari a clean (non-redirected) copy for navigations.
Ideas not yet tried: bump to `?v=7`; Fodibey's own comment says to leave `apple-mobile-web-app-status-bar-style` at default (we use `black-translucent`, `layout.tsx` metadata `appleWebApp`) because it shifts standalone content; test on a **real device** after deleting the icon *and* waiting a few seconds on the page before tapping Share; check the OG image is not the thing iOS shows (`og-square.png` was added as the first og:image).
Not caused by Cloudflare: DNS is DNS-only, all responses come from Vercel and every icon returns 200.

## Traps (learned the hard way)
- **Never `next build` into a dist dir a running server uses.** Use `NEXT_DIST_DIR=.next-xxx`, then `git checkout tsconfig.json` (Next rewrites `include`) and delete the dir. `.next-sn/` may still exist from the video work.
- Never `pkill -f`; stop servers by port (`fuser -k <port>/tcp`).
- `suncalc` is pinned at 1.9.0. Don't upgrade.
- DB access: direct host is IPv6-only; use the Supabase pooler (`aws-0-ap-southeast-1.pooler.supabase.com:5432`, user `postgres.<ref>`) and read credentials **in-process** from `vaahaka.txt` (gitignored). Never echo or commit anything from it (it also holds the service-role key and `FODIBEY_API_KEY`).
- Scan staged files for secrets before every push.
- Snap Firefox can't read profile dirs under `/tmp`; the marketing tools keep profiles inside the project (`.shot/`).
- The owner's rules: back up any config file as `<file>.bak-YYYY-MM-DD` before editing and say where; no `sudo` (give the command to run with `!`); short plain-language answers; they/them pronouns. Many `*.bak-2026-10-2x` files are lying around untracked; they are safe to delete once the owner OKs it.
- Don't touch `xplorer`/`mx-test`, `itnvend.com`, the owner's other systemd services, or `~/Desktop/S23FE-backup-2026-10-28`.
