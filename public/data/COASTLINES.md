# Illustrated Maldives land layer

Source: geoBoundaries gbOpen, MDV ADM0, boundary ID MDV-ADM0-21348113.
https://www.geoboundaries.org/
https://github.com/wmgeolab/geoBoundaries/tree/main/releaseData/gbOpen/MDV/ADM0

Derived from Sentinel-2 10-Meter Land Use/LandCover, boundary year 2021.
License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/
Attribution: geoBoundaries / William & Mary geoLab; Sentinel-2 source data.

Downloaded 2026-10-28; original metadata stored in maldives-coastlines-source.json.
The GeoJSON geometry is unchanged, with whitespace removed. Includes 1,295 polygon parts.
The illustrated map adds decorative sand/surf outlines; they do not describe reef boundaries,
water depth, or actual beach width. Recent reclamation may not appear in the 2021 geometry.
Street mode provides OpenStreetMap's separately maintained map for detailed reference.

Reproduction: download geoBoundaries-MDV-ADM0.geojson from the source directory above
(using media.githubusercontent.com for its Git LFS payload), then serialize as compact JSON.
