Keep Ihusaas close

In Safari, add Ihusaas for one-tap access.

  1. Tap Share.
  2. Choose Add to Home Screen.
  3. Keep Open as Web App on, if shown, and tap Add.

Replacing a black “I” shortcut? Remove the old shortcut first, then add it from this page.
